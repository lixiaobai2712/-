# 待办事项清单 — 项目介绍

一个纯前端单文件 HTML 个人效率工具，整合**待办管理**、**日期规划**、**工作登记**和**自我提醒**四大模块，所有数据通过 localStorage 本地持久化，无需服务器。

## 快速开始

用浏览器打开 `todo.html` 即可使用。所有数据保存在浏览器本地存储中。

## 桌面悬浮球 + 手机版联动

运行 `todo_tray.exe`（桌面右下角阿米娅悬浮球）后：

- 悬浮球左键点击 → 弹出小窗查看今日任务/全部待办/进度，可直接勾选、滚轮滚动
- 悬浮球右键 → 查看待办 / 打开待办页面 / **手机版地址** / **云端上传 / 云端下载** / 退出
- 网页与悬浮球通过 `127.0.0.1:8899` 双向同步（网页 8s 轮询）

### 📱 手机版
- 手机连上**同一 WiFi**，浏览器打开 `http://<电脑IP>:8899/mobile`（电脑 IP 见悬浮球右键「手机版地址」）
- 手机端支持：任务勾选/新增/进度、思路侧边栏（按日期分页 + 修改时间）
- 不在同一 WiFi 时，手机改动**只保留在本地**，连上后自动补同步
- 不同网络时用坚果云手动同步（手机版「☁️ 同步」按钮，或悬浮球右键「云端上传/下载」）

### 📲 手机版变成 App（PWA）
- 手机浏览器打开待办页面后，浏览器菜单选**「添加到主屏幕 / 添加到桌面」**
- 桌面会生成「待办」图标，点开全屏运行，和独立 App 一样
- Android（Chrome）：菜单「添加到主屏幕」；iOS（Safari）：分享按钮 →「添加到主屏幕」
- 页面已带 PWA 配置（manifest + 图标），无需安装任何东西

### ☁️ 坚果云同步（可选，方案B）
1. 注册坚果云账号，网页版新建文件夹（如 `待办同步`）
2. 账户信息 → 安全选项 → 生成**应用授权码**（非登录密码）
3. 填入 `cloud_config.json`（url 需 URL 编码中文路径；未配置时点同步只会提示，不影响本地使用）
4. 同一 WiFi 的自动同步是方案A，坚果云是不同网络时的手动兜底（方案B）

### 🔄 冲突裁决
- 全局单调计数器 `syncSeq` 优先，任务级 `updatedAt` 时间戳兜底
- 任务逐条合并取较新者，思路按日期 `ts` 合并
- 手机端离线期间的改动在重连后自动合并，不会丢失

### 🔧 重新打包（改过 todo_tray.py 后）
```bash
pyinstaller --noconfirm --onefile --windowed --icon "可爱的阿米娅-人为修改.ico" --add-data "可爱的阿米娅-人为修改.ico;." todo_tray.py
```

## 功能模块

### 📋 待办事项清单（中间面板）

| 功能 | 说明 |
|------|------|
| 添加任务 | 输入文字回车或点击添加 |
| 完成标记 | 勾选 → 进度 100%、取消收藏、移至末尾、自动登记到工作记录 |
| 收藏 ⭐ | 收藏项置顶显示 |
| 进度条 | 每个任务 0-100% 进度，顶部显示全局平均进度 |
| 清除已完成 | 一键清理所有已完成任务 |

#### 今日任务模式
- 切换按钮：`切换至今日任务模式` ↔ `切换至所有任务模式`
- 今日模式下添加的任务自动同步到所有任务列表
- 今日模式完成的任务自动隐藏
- 第二天今日列表自动重置
- 所有任务模式下可点击 📅 按钮或**长按拖拽**将任务添加到今日清单
- 重复添加会提示「已经加过了哦」

### 📅 日期备忘（左侧面板 — 备忘模式）

- 选择日期 + 输入备注内容
- 按日期升序排列，越近的越在上面
- 支持删除

### 📋 日期规划（左侧面板 — 规划模式）

- 标题旁切换按钮在备忘和规划之间切换

**时间点**：日期 + 时间 + 内容，按日期分组按时间排序

**时间段**：起止日期区间 + 内容，跨天蓝色条幅展示
- 迷你日历：月视图，左键点击两个日期自动高亮区间
- **右键清空**，点击已选点可取消
- 支持纯文字添加（不设日期），后续可点击补选

**过期提醒**：未完成的过期条目左侧红色标记

### 📝 每日工作登记（右侧面板 — 上）

- 每天自动清空，日期标签页可回溯历史
- 勾选完成待办任务后自动追加 `序号. 任务名`
- 内容可手动编辑

### 💬 明天要说的话（右侧面板 — 下）

- 写一句话给明天的自己
- 次日打开文件自动弹窗提醒
- 弹窗同时显示昨日未完成的任务
- 确认后当天不再弹出

## 数据存储

所有数据保存在浏览器的 `localStorage` 中，包含以下键：

| Key | 内容 |
|-----|------|
| `my_todo_list_v2` | 待办任务列表 |
| `my_date_notes` | 日期备忘 |
| `my_date_plans` | 日期规划 |
| `my_today_data` | 每日今日任务 ID |
| `my_today_mode` | 当前视图模式 |
| `my_panel_mode` | 左侧面板模式 |
| `my_worklog` | 每日工作登记 |
| `my_tomorrow_msg` | 明日消息 |
| `my_tomorrow_dismiss` | 弹窗关闭状态 |
