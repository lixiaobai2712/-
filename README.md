# 待办事项清单 — 项目介绍

> 📌 本文件是**日常使用说明**；开发/维护交接请看 [`HANDOVER.md`](HANDOVER.md)（架构、数据模型、API、打包、已知问题）。

一个纯前端单文件 HTML 个人效率工具，整合**待办管理**、**日期规划**、**工作登记**和**自我提醒**四大模块，所有数据通过 localStorage 本地持久化，无需服务器。

## 快速开始

用浏览器打开 `todo.html` 即可使用。所有数据保存在浏览器本地存储中。

## 桌面悬浮球 + 手机版联动

运行 `todo_tray.exe`（桌面右下角阿米娅悬浮球）后：

- 悬浮球左键点击 → 弹出小窗查看今日任务/全部待办/进度，可直接勾选、滚轮滚动
- 悬浮球右键 → 查看待办 / 打开待办页面 / **手机版网址** / **立即云同步** / **Gitee 同步设置…** / **开机自启** / 退出
- 网页与悬浮球通过 `127.0.0.1:8899` 双向同步（网页 8s 轮询）

### ☁️ 手机版（Gitee + Netlify，推荐）

校园网/公司网常开启终端隔离，手机和电脑互相访问不了。现在手机端不再依赖电脑在线：

```
手机 PWA（Netlify HTTPS） ⇄ Gitee 私有仓库 sync.json ⇄ 电脑悬浮球
```

**第一次使用需要手动准备（只做一次）：**

1. **Gitee**：登录 [gitee.com](https://gitee.com) → 新建**私有仓库**（如 `todo-data`，勾选“使用 Readme 初始化”，默认分支通常为 `master`）。
2. **令牌**：[个人访问令牌](https://gitee.com/profile/personal_access_tokens/new) → 名称随意（如 `todo-sync`）→ 权限只勾 **projects** → 生成并复制（只显示一次）。
3. **Netlify**：打开 [Netlify Drop](https://app.netlify.com/drop)，把项目里的 **`docs` 文件夹**整个拖进去 → 得到 `https://xxx.netlify.app`。建议先在 Site settings 里改成固定名字，再安装 App。
4. **电脑**：右键悬浮球 →「☁️ Gitee 同步设置…」→ 填仓库 `owner/repo`、令牌、Netlify 网址 →「保存并测试」→「立即同步」。再勾选「🚀 开机自启」。
5. **手机**：Chrome 打开 Netlify 网址 → 右上「☁️ 云同步」→ 填同一个仓库和令牌 → 保存并测试 → 立即同步。
6. **安装到桌面**：Chrome 菜单 →「安装应用 / 添加到主屏幕」。从桌面图标打开即为独立窗口。

同步是自动的：电脑默认每 120 秒、手机在前台时每 120 秒检查一次；本地改动会稍后自动推送。电脑关机时手机照样能增删改，联网后补同步。

> ⚠️ 令牌等同于仓库密码：**不要发到聊天、不要提交到 git、不要写进网页文件**。它只保存在电脑的 `cloud_config.json`（已 gitignore）和手机浏览器 localStorage 中；怀疑泄露可在 Gitee 立即撤销。

### 📱 局域网备用访问

同一 WiFi 且没有终端隔离时，也可以直接打开 `http://<电脑IP>:8899/mobile`（IP 见悬浮球右键「手机版网址」）。页面内容和 Netlify 版完全一致，同样走 Gitee 同步。

### 📲 手机版变成 App（PWA）

- Android Chrome：菜单「安装应用」或「添加到主屏幕」
- iOS Safari：分享按钮 →「添加到主屏幕」
- 已带 manifest + Service Worker：断网也能打开页面、查看和编辑本地数据

### 🔄 冲突裁决

- 全局单调计数器 `syncSeq` 优先，任务级 `updatedAt` 时间戳兜底
- 任务逐条合并取较新者，思路按日期 `ts` 合并
- 删除使用墓碑（tombstone），删除终局，不会复活
- 手机只负责任务/墓碑/思路三个 key，电脑的今日映射、计划、工作日志不会被手机旧快照覆盖
- 两端内容语义相同就**不写 Gitee**，避免互相回环刷提交

### ⚙️ 配置参考

真实配置由设置窗写入 `cloud_config.json`（不入库）；字段说明见 [`cloud_config.example.json`](cloud_config.example.json)。

### 🔧 重新打包（改过 todo_tray.py 或 docs/ 后）

```bash
pyinstaller --noconfirm --onefile --windowed --icon "可爱的阿米娅-人为修改.ico" --add-data "可爱的阿米娅-人为修改.ico;." --add-data "docs;docs" todo_tray.py
```

`todo.html` 不打进 exe，仍需放在 exe 同目录（方便直接改内容）。

## 功能模块

### 📋 待办事项清单（中间面板）

| 功能 | 说明 |
|------|------|
| 添加任务 | 输入文字回车或点击添加 |
| 完成标记 | 勾选 → 进度 100%、取消收藏、移至末尾、自动登记到工作记录 |
| 收藏 ⭐ | 收藏项置顶显示 |
| 进度条 | 每个任务 0-100% 进度，顶部显示全局平均进度 |
| 清除已完成 | 一键清理所有已完成任务 |

#### 今日任务模式
- 切换按钮：`切换至今日任务模式` ↔ `切换至所有任务模式`
- 今日模式下添加的任务自动同步到所有任务列表
- 今日模式完成的任务自动隐藏
- 第二天今日列表自动重置
- 所有任务模式下可点击 📅 按钮或**长按拖拽**将任务添加到今日清单
- 重复添加会提示「已经加过了哦」

### 💡 思路整理侧边栏（右侧抽屉 ◀，电脑/手机通用）

左侧随手记录，右侧按日期列表切换（今天固定第一行，其余按日期倒序，显示最后修改时间）。**编辑与预览同屏**：在编辑框输入，下方实时渲染出颜色与链接，写完马上看到效果。

**一、红黄绿轻重缓急标记（蜡笔）**

- 点工具条「🖍 蜡笔」弹出选色面板：**红**（又急又重要）/**黄**（重要但不急）/**绿**（不急也不重要）+ 橡皮
- 选色后进入涂抹态：电脑按住鼠标涂抹、手机点一下，给整行上色；可连续涂多行
- 打标记后行首带一个对应颜色的小球；**相邻同色的行渲染时自动合并成一整块，小球只出现在这块最前面**
- 再点「🖍 蜡笔」退出涂抹态；也可直接在编辑框敲 `[r] 今天必须交`、`[y] 重要但不急`、`[g] 可以往后放`

**二、悬停说明（超链接式，实时渲染）**

- 输入 `[[显示文字|详细内容]]`，下方预览**立即**变成蓝色链接，鼠标放上去（手机点一下）就弹出详细内容
- 或点工具条「🔗 说明」填两个框自动插入：**显示的文字** + **详细内容**（详细内容留空则显示文字本身）
- **双击链接（电脑端）**可重新编辑显示文字与详细内容；一行里可以写多个说明

> 标记与说明**都写在正文文本里**，不新增任何存储字段 —— `my_ideas` 仍是 `{日期: {text, ts}}`，因此云端/手机同步格式完全不变，旧数据无需迁移。

### 📅 日期备忘（左侧面板 — 备忘模式）

- 选择日期 + 输入备注内容
- 按日期升序排列，越近的越在上面
- 支持删除

### 📋 日期规划（左侧面板 — 规划模式）

- 标题旁切换按钮在备忘和规划之间切换

**时间点**：日期 + 时间 + 内容，按日期分组按时间排序

**时间段**：起止日期区间 + 内容，跨天蓝色条幅展示
- 迷你日历：月视图，左键点击两个日期自动高亮区间
- **右键清空**，点击已选点可取消
- 支持纯文字添加（不设日期），后续可点击补选

**过期提醒**：未完成的过期条目左侧红色标记

### 📝 每日工作登记（右侧面板 — 上）

- 每天自动清空，日期标签页可回溯历史
- 勾选完成待办任务后自动追加 `序号. 任务名`
- 内容可手动编辑

### 💬 明天要说的话（右侧面板 — 下）

- 写一句话给明天的自己
- 次日打开文件自动弹窗提醒
- 弹窗同时显示昨日未完成的任务
- 确认后当天不再弹出

## 数据存储

所有数据保存在浏览器的 `localStorage` 中，包含以下键：

| Key | 内容 |
|-----|------|
| `my_todo_list_v2` | 待办任务列表 |
| `my_date_notes` | 日期备忘 |
| `my_date_plans` | 日期规划 |
| `my_today_data` | 每日今日任务 ID |
| `my_today_mode` | 当前视图模式 |
| `my_panel_mode` | 左侧面板模式 |
| `my_worklog` | 每日工作登记 |
| `my_tomorrow_msg` | 明日消息 |
| `my_tomorrow_dismiss` | 弹窗关闭状态 |
| `my_schedule_data` | 课表/日程数据 |
| `my_ideas` / `my_ideas_open` / `my_ideas_pos` | 思路整理：`{日期: {text, ts}}` / 抽屉开合 / 上次查看的日期 |
| `my_ideas_mode` / `my_ideas_pen_color` | 思路模式（read/edit/pen）/ 上次选中的画笔颜色 |
| `my_deleted` | 删除墓碑 `{任务id: 时间戳}`（跨端同步删除） |

## 技术栈

- 纯 HTML + CSS + JavaScript（ES5 兼容）
- 无框架、无依赖、无构建工具
- localStorage 持久化
- PWA：manifest + Service Worker，可安装到手机主屏幕、离线打开
- Gitee Contents API（HTTPS + 私有仓库 + 个人令牌）负责跨网络同步
- 电脑端：Python + tkinter + pystray + 标准库 HTTP 服务
- Flexbox + Grid 响应式布局
- HTML5 Drag & Drop + Touch Events

## 浏览器兼容

- Chrome / Edge / Firefox 最新版
- 移动端 Safari / Chrome
- 不支持 IE
